# Private AI Studio

منصة خاصة لإنشاء وتحرير الصور بالذكاء الاصطناعي، بواجهة عربية واتجاه RTL، وتشغيل محلي افتراضي على حاسوب Windows.

المشروع في **المرحلة 0**: تأسيس البنية، توثيق القرارات، وتثبيت أدوات التحقق. راجع [PLANS.md](PLANS.md) للحالة الحالية و[دليل التطوير](docs/DEVELOPMENT.md) للتشغيل.

## مبادئ ثابتة

- المهام محفوظة على الخادم وتستمر عند انقطاع الهاتف أو المتصفح.
- خدمات الاستدلال داخلية ومربوطة بالـ loopback.
- التشغيل المحلي هو الافتراضي، ولا يوجد انتقال تلقائي إلى خدمة مدفوعة.
- قيود RTX 3060 بذاكرة 6 GB جزء من التصميم.
